## Sobre o projeto
O jogo consiste em um protótipo no qual o personagem é uma bola que se desloca por um mapa em formato de labirinto, coletando itens ao longo do percurso. O objetivo é simples: percorrer o mapa e coletar os 20 itens disponíveis, condição necessária para a vitória.

# O que o projeto faz
o jogador consgue se movimentar usando as teclas WASD andando pros lados e para frente, a camera segue o personagem continuamente, e a bola e os elementos do mapa tem fisica, como se a bolinha cair em algum buraco ela ira cair normalmente
ao chegar perto de um item o item some e é adicionado ponto ao placar, ao coletar todos os itens o jogador recebe uma mensagem de vitoria em sua tela
